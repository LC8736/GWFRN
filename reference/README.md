# Reported values

These CSVs contain the numerical targets reported in manuscript Tables 2–5.
The PDFs are Figures 2–3 rebuilt from the supplied inputs and saved predictions.
Tables 2–4 retain the four decimal places available in the reported simulation
summary. Table 5 retains the full precision of the original annual summary;
its SDs are across the 20 annual metrics.

They are provided for comparison, not as newly fitted results. Only numerical
comparison reads these CSVs; fitting and summary calculations never substitute
their values. Fresh outputs are written to `results/`; a missing or failed
computation never falls back to the reference files.
